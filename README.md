## ABET – EAC – Student Outcome 3

**Criterio: Capacidad de comunicarse efectivamente con un rango de audiencias.**

Con las empresas y los transportistas se emplea un lenguaje centrado en sus necesidades y actividades; con el equipo y el docente se utilizan requisitos, modelos, interfaces funcionales y evidencias técnicas para explicar el diseño y el avance del producto.
